# 추출 단계 Gemini 비용 추정

> **기준일:** 2026-10-20
> **결론:** 추출 단계 전체에서 Gemini 약 **454회** 호출, 약 **63만 입력 + 36만 출력 토큰** → **약 $1.8 (약 2,600원)**
> (토큰 사용량을 호출 때 저장하지 않아서, **호출 횟수 × 실측한 호출당 토큰**으로 추정한 값이에요.)

<br>

## 1. 비용이 드는 건 Gemini뿐

| 도구 | 용도 | 비용 |
|:---|:---|:---:|
| pdfplumber | 본문·표 추출 | 무료 (로컬) |
| rapid-layout | 490쪽 영역 분석 | 무료 (로컬 CPU, 약 15분) |
| RapidOCR | 이미지 속 글자, 숫자 검증 | 무료 (로컬 CPU) |
| **Gemini (`gemini-3.6-flash`)** | 깨진 표, 그래프·그림·절차도·수식 해석 | **유료** |

| 구분 | ~ 2026-12-31 | 2027-01-01 ~ |

- 무료 티어도 있어요. 무료 티어 키라면 비용은 $0이지만, 입력 내용이 Google 제품 개선에 쓰여요.
- 출처: [Gemini API 가격 (ai.google.dev)](https://ai.google.dev/gemini-api/docs/pricing)

<br>

## 3. 호출 1회당 토큰 (실측)

대표 영역 3개를 실제로 호출해서 `usage_metadata`로 쟀어요.

| 영역 | 이미지 크기(200dpi) | 입력 | 출력 | 그중 생각(thinking) |
|:---|:---:|---:|---:|---:|
| 그래프 (정책금융 12쪽) | 582×410 | 1,411 | 1,301 | 1,180 |
| 수식 (정책금융 96쪽) | 1186×331 | 1,265 | 722 | 599 |
| 장식 (일러스트) | 779×449 | 1,419 | 243 | 241 |

> **출력의 대부분이 "생각" 토큰이에요.** 그래프 답변 자체는 120토큰인데 생각이 1,180토큰이에요. 출력 단가가 입력의 5배라서 비용의 약 3/4이 출력(생각)에서 나와요.

**추정에 쓴 값:** 입력 1,400 / 출력은 내용이 있는 그림 1,000, 장식 250

<br>

## 4. 호출 횟수와 비용

| 작업 | 호출 | 입력 토큰 | 출력 토큰 | 비용 |
|:---|---:|---:|---:|---:|
| 깨진 표 3개 (`03_gemini_tables.py`) | 3 | 4,500 | 4,500 | $0.02 |
| 그림 처리 1차 (샘플 시험 포함, 장식 87) | 270 | 378,000 | 204,750 | $1.05 |
| 그림 처리 2차 (설명 문장·다이어그램·수식, 장식 36) | 176 | 246,400 | 149,000 | $0.74 |
| 토큰 측정 (이 문서용) | 3 | 4,095 | 2,265 | $0.01 |
| API 키 확인 | 2 | 40 | 400 | $0.00 |
| **합계** | **454** | **633,035** | **360,915** | **$1.83** |

- 입력 $0.47 + 출력 $1.35 = **약 $1.83** (환율 1,400원 가정 시 **약 2,600원**)
- 2027년 단가로 같은 작업을 다시 하면 **약 $3.66**
- 호출이 실패한 경우(PDF 렌더링 충돌, 잘못된 API 키)는 Gemini까지 가지 않았거나 요청이 거절돼서 과금이 없어요.

## 6. 앞으로 비용 줄이기 / 정확히 재기

| 방법 | 효과 |
|:---|:---|
| 결과 캐시 유지 (지금 구조) | 이미 처리한 영역은 다시 안 불러서, 다시 돌려도 새 영역만 과금 |
| 생각 토큰 줄이기 (`thinking` 수준을 낮게) | 출력 비용의 대부분이 생각이라 효과가 큼. 단, 그래프 해석 품질 확인 필요 |
| 장식 사전 필터 (rapid-layout `chart`·크기 기준) | 장식 판정에 쓰는 호출(이번에 120여 회)을 줄임 |
| 호출 결과에 `usage_metadata` 저장 | 추정이 아니라 실제 토큰 합계로 계산 가능. **Agent 평가 단계에서는 필수** (과제 요구사항: 모델 호출 수·토큰 사용량 기록) |
